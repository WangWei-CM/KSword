2. 使用独立 Python 环境，按当前 agent 的原生格式注册 stdio 服务，保留其它 MCP 配置。
3. 根据我的回答配置启动和权限策略；不要自行改变权限或重启已有 KSword。
4. 验证工具发现和只读连接，不执行驱动装卸、结束进程或内存写入。
