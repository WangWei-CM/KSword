# 详情共享框架接入清单（2026-10-11）

本清单记录主程序详情窗口的共享框架入口及保留的业务边界。日期按本轮用户会话计算。它是源码接入记录，不是所有窗口已经完成运行验收的声明；本轮按用户要求不运行自动测试、GUI 或伪窗口。

用户最新要求是做成共享框架，让适用入口复用同一套结构。不得继续在每个窗口复制摘要、导航、卡片及几何修正代码；现有字段、模型、页签索引、编辑事务和危险动作保持原归属。

## 共享入口与职责

| 共享入口 | 职责 | 不接管的内容 |
|---|---|---|
| `UI/DetailPresentation::InstallDetailWindowFramework` | 统一安装摘要、页面外壳、表单适配及结构化字段投影；重复调用及惰性页面由共享实现处理 | 驱动操作、采样、业务模型、原始数据解析和确认语义 |
| `CreateDetailSummaryHeader` | 全宽对象摘要，右侧可放原有动作 | 不解析路径、PID 或对象身份 |
| `CreateDetailFieldProjection` | 将原 `StructuredFieldView` 文档投影为无描边卡片；原视图保留文档与导出能力 | 不解析文本报告，不伪造字段，不改变数据来源 |
| `CreateDetailCard` / `ConfigureDetailForm` | 卡片标题在内部；字段按宽度换行；独立正文允许缩小 | 不把表格、专业编辑器或长文本当作固定高度字段 |
| `UI/DetailDialogChrome::CreateDetailTabShell` | 复用现有 Tab，提供分组侧导航 | 不改页签顺序、当前页、启用状态或业务信号 |
| `UI/GlobalDialogTheme` | 普通 `QDialog` 的统一安装与主题兜底接入点 | `QMessageBox`、Qt系统选择器、明确保留结构的共享设置页、原生插件宿主 |
| `UI/SecondaryPageLayout` | 配置、编辑、安装和确认工具的共享表单、页签、底栏规范 | 不将简单事务强行改成详情侧导航 |
| `UI/ThemedMessageBox` / `UI/WindowChrome` | 消息框及系统原生窗口边缘 | 不改变按钮角色、返回值、关闭语义或专用无边框窗口类型 |

`ProcessDetailWindow` 是 `QWidget`，不能只靠扫描 `QDialog` 覆盖。服务属性与句柄字段还存在主页面内嵌详情，同样必须通过其明确构造入口登记。统一安装已由普通弹窗的 Polish/Show 和主题刷新入口接通；配置/工具二级窗口同样安装结构，颜色仍由原共享主题拥有。设置页通过 `ksword_detail_keep_layout` 保留 `SettingsPresentation`，Qt 文件/颜色/字体/单项输入选择器保留系统结构。

## 已定位的业务几何问题与边界

- VirusTotal 报告移除外层整页滚动；报告树、引擎表及 HTML 自己滚动。基础信息表不再把全表高度同时设为 minimum/maximum，数据多时在表内滚动。IOC 动作使用共享 `FlowLayout`。
- 注册表权限的两个内置编辑器允许缩小，没有再用面向自然高度字段的参数列容器承载可滚动编辑器；原始/目标 DACL 保持同时可见。
- 卸载驱动、HVM 命中、监控通用文档、剪贴板内容/栈及在线扫描通用结果使用屏幕约束的响应窗口几何。
- 旧决策框及监控创建目标的最小尺寸由共享框架约束到可缩放范围；原始专业表格可在自身视口横向滚动，外层不再重复滚动。
- 多页侧导航来自原 Tab；参数确认/专业工具是否保留自身 Tab 按业务分类，不以强行创建侧导航作为覆盖证据。

## 交付状态解释

“显式接入”表示构造源引用共享组件；“全局覆盖入口”表示普通弹窗由统一安装路径负责；“保留二级规范”表示共享工具/编辑工作流有明确所有权。三者都不等同于真实窗口缩放、DWM 系统外沿、每项危险动作或硬件业务已经运行验收。

本清单不运行自动测试、GUI 或伪窗口，也不把编译通过当作视觉验收。主程序能编译时按用户要求交主程序，由用户自行检查效果。


本轮框架实现已集中为 `DetailPresentation.cpp`（摘要/卡片/字段分栏）、`DetailFieldProjection.cpp`（原文档投影）、`DetailWindowFramework.cpp`（安装、惰性页及几何整理）。进程独立的旧概览投影已移除；复用共享实现。Splitters中的字段视图同样通过占位替换接入，保留原分栏比例。卡片直接绘制唯一圆角实底，卡片间和滚动底层使用Window，避免截图中的异常色块与黑色接缝。

字段投影保留原搜索、格式、复制和导出控件：搜索分组名显示整组，程序调用 `setPresentation()` 与用户下拉切换都同步到卡片/树形显示。自然高度卡片使用既有正文滚动，树形模式由原树视图滚动，不会把唯一滚动区关闭。
