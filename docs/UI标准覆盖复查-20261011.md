# UI 标准覆盖复查（2026-10-11）

按页面用途检查主窗口各模块的构建入口、主题绑定和外围布局。本轮是源码检查与实现，实际窗口的深浅主题、缩放和交互效果仍需运行验收；不把构建成功等同于视觉验收。

## 外框标准

- 外角过渡只用于“方角工作区包着圆角内容”。普通 `StylePageTabsContentFrame` 仅统一留白，不代表外部有方框；真正主导航用 `StyleSquarePageTabsFrame` 明确登记。资格只沿整页单子 Tab 转交，复合工具区、分隔区和卡片内的 Tab 不继承。
- 圆角在最外层框架，不覆盖内部组件已有圆角。内部半径 8px，普通间隔 6px，外半径 14px，内外圆心重合。
- 等边留白只由一层负责。显式接入的 Tab 框架接管直接页面根布局，或项目自适应滚动壳内容的根布局；内部卡片和参数面板的 16px 留白保留。
- 页面只承载另一组已接入 Tab 时，外层让出留白，交给内层。惰性占位壳通过明确属性登记，避免把壳和实际页的边距相加。
- 子 Tab 的 8px 缩进仅作用于标签栏，不再把整个页面右移。横向与竖向 Tab 都支持外角。
- 删除旧的“首工具条局部补角”和自动清零父布局顶部的路径，避免覆盖内部圆角或制造不等边留白。
- 外角使用四个小角片，无新增描边和全高透明覆盖层。背景穿透模式不绘不透明角片。

### 方框归属修正

- 明确主导航：进程、文件、驱动、硬件、句柄、权限、监控、杂项、网络、内核、注册表。注册表移除根层重复的4px，由主框统一6px。
- 整页根新增过渡：内存6px，启动项/窗口/Other各4px，HVM/扫描/转储各8px，沿用其页根原有留白。已有欢迎、服务页根保留。
- Cross-View、注册表右侧、驱动对象详情、WinAPI及其他内嵌结果Tab只整理留白，不绘无依托的外圆。
- 内核三级导航、权限账户等纯转交页面继续从主导航继承；内核规则/日志等有其他并列内容的区域不继承。
- Scanner/Minidump等独立页根挂入杂项页后，由外围框架负责；页根角片会依据宿主和实际margin停止，避免嵌入后再次出现外圆。
