## 页面接入补漏

| 页面 | 原问题 | 修正 |
|---|---|---|
| BCD 参数页 | Combo 已接共享主题，随后又被旧局部输入 QSS 覆盖；其它独立字段仍走旧底色 | 移除旧输入配方，文本、下拉与超时参数明确接入 `StyleStandaloneInput` |
| 磁盘编辑器参数 | 外部路径、地址、格式等参数仍使用旧输入配方 | 外部参数接共享输入层；专业 HEX 编辑器内部保留 |
| 权限访问评估、身份启动 | 两组各三个独立字段未登记共享输入主题 | 明确登记输入，不改变验证、令牌和启动流程 |
| HWID 调度、电源调节 | 六个文本字段及八个数值框仍缺共享输入接入 | 登记共享字号高度、圆角、底色和状态；硬件操作条件保持 |
| 文件详情 | 完整业务主题与普通弹窗主题器共同改根 QSS/palette | 声明业务根主题所有权，通用框架仅安装结构，真实颜色改变才更新 |

驱动操作与对象查询的字段已通过字段列表统一登记，本轮没有重复改动。剪贴板、桌面绘制及专业工作台具有持续业务语义，不因页面隐藏而停止其工作。

## 共享热路径

| 入口 | 原触发链 | 修正 |
|---|---|---|
| `ThemeBinding` | 每次新绑定先扫描全部登记项；换肤排队对增长的 QList 逐项 contains | 登记使用稳定节点，销毁原位移除；哈希集合去重，实际刷新队列仍用 QPointer 并保留顺序与嵌套刷新 |
| 普通页 Tab 与圆角外框 | 重复接入写相同 QSS；同页面布局事件反复安装过滤器、强制重画四角 | 相同内容不写入，宿主不变不重装过滤器；真实几何、主题、重挂和 DPR 变化仍刷新 |
| 内容面板 | 一个面板的 outline 改变广播全应用主题刷新 | 只替换该面板自己的主题绑定 |
| 参数编辑器 | 相同主题也重写 QSS、palette、字体，并全文 rehighlight；重复 finish 累加 padding | 只有实际颜色/样式改变才重高亮，几何规则保持幂等 |
| 详情外观与侧导航 | 反复追加同一 Chrome；LayoutRequest 后重新写文字、图标和状态 | 与框架共用完整样式块，主题拥有者让出；导航按真实变化写入，默认图标复用，比较源图标身份避免反复覆盖主题加工结果 |
| 详情镜像浮窗 | 隐藏的复用浮窗仍替换全文，重复文本也重建文档 | 隐藏时延后镜像，显示入口先读取最新源；相同文本保留原文档、选择及高亮缓存 |

共享主题队列的改变消除了由源码可见的重复线性查找；没有测量启动时间或帧率，不给出未经实测的性能提升比例。最外层 `8+6=14px` 同心圆角、6px 四边留白、内部圆角及透明背景保护保持。

## 采样与可见投影

- 进程详情性能历史仍逐样本入库并裁剪到原 1800 点。隐藏性能页延后拆分八个数据向量及六图动画，Show 提交最新快照；切换身份/清空时提交空图，避免旧曲线残留。
- CPU 核心/线程历史只由新样本或初次创建追加。主题、语言及重新显示只刷新外观；隐藏线程卡片延后排序/尺寸提交，绘制跳过视口外卡片，历史持续保留。
- 主/父进程图标按身份、路径、主题代次和 DPR 去重；相同路径/命令行不反复 setText。父进程活性、文件存在性和后台枚举继续执行，不用长期缓存代替外部状态查询。
- 硬件逐核表复用原 QTableWidgetItem，改变的文本才写入，避免每秒重新分配全部 `7 × 逻辑CPU数` 个项。
- 磁盘监控隐藏时保留 ETW 消费、速率基线、活动缓存与存储采样；只合并进程表/活动表的 UI 提交，Show 读取最新缓存。共享右键菜单/Ctrl 提交屏障继续生效。
