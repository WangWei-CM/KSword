# UI 逐页复查：进程、内存、网络、文件、监控、句柄（2026-10-11）

本轮按实际构造入口、`addTab/insertTab`、惰性首次进入和详情工厂展开清单。源文件均相对 `Ksword5.1/Ksword5.1/`。记录的是源码覆盖与具体修正，不是运行验收；按用户要求未运行测试、GUI、伪窗口或本组独立构建。

## 共同判定

- 主页面外框沿 `StylePageTabsContentFrame`：最外层半径 14 = 内部 8 + 间隔 6，留白只由一层负责；纯嵌套 Tab 交给内层，`ksword_page_frame_host` 标记惰性代理。专业编辑器内部不再重复套外框。
- `StylePrimaryToolbar/StylePrimaryContentPanel` 负责固定层级底面；`StylePrimaryCombo/StyleStandaloneInput/StyleSearchField` 负责对应输入和文字对比；`NormalizeToolbarRow` 负责同排高度与 8px 间距。已有分段控件保持自身连续边缘。
- 参数工作区由 `ParameterWorkspace::finish`、`StyleParameterFields`、`StyleWorkspaceTextViews` 统一；不因为子页在详情窗口内就遗漏其网格字段。
- 详情窗口沿 `ConfigureDetailDialogRoot/InstallDetailWindowFramework/ApplyDetailDialogChrome`，普通 QDialog 通过 `GlobalDialogTheme` 安装。字段文档使用 `CreateDetailFieldProjection`；主页面 14px 外框不强加到详情正文、专业编辑器或系统文件选择器。
- 表格取证栏保留 Full/Compact/None 的既有逐表决策。表头、行语义色、圆角由实际 `TablePresentation/RoundedViewSurface` 管理，禁止重新写透明表头或旧矩形按钮盖住共享样式。
- 状态“已追踪”表示入口、布局、最终共享所有权均有源码链路；“已修复”列出本轮实际缺口；“专业保留”或“未开放”是明确用途分类，不等同于遗漏。

## 本轮修复

1. `ThreadStackWindow`、`FileMappedProcessWindow` 删除本地 `buildOpaqueDialogStyle`。该旧块包含透明表头和所有抽象滚动区强制底色，随后又追加共享详情主题；现在由现有共享入口唯一接管，四个纯图标动作显式 Solid。
2. `ProcessMessageHookWindow` A/B 状态更新不再先写旧 `presetButtonStyle` 再交给分段宿主；范围下拉使用共享绑定，列菜单和结果菜单补齐不透明主题。
3. 文件详情七个元数据三级页及权限编辑页补 `StyleParameterFields/StyleWorkspaceTextViews`。字段并不都位于 QFormLayout，不能依赖详情框架的表单处理覆盖全部网格。字符串参数、HEX 外部偏移/读取范围单独登记，专业编辑器内部保持原所有权。
4. 进程详情操作、原始令牌参数页补共享字段处理。Pool ETL 分组和调用栈下拉及四个动作补显式绑定。
5. 句柄 Object Header 直接以异步结果构造唯一字段文档，删除隐藏 QTreeWidget 的 clear/item 分配/菜单延期。Object Type 下方旧键值树改为同一文档投影；有效选择仅提交一次完整文档，空选择才清空，保留对象类型清单、异步身份校验和现有字段。
6. WMI/ETW 与进程定向监控折叠段在工厂对实际段、内容宿主和标题按钮分别登记幂等主题绑定，删除 StyleChange 下的全页 findChildren + 无条件 setStyleSheet 链。折叠状态与采集保持原实现。
7. 内存主 Tab 图标表补缺失的“篡改检测”项，避免其误用 DDMA 图标并使 DDMA 无图标。
8. 下载表格刷新除当前 Tab 判断外再检查 NetworkDock 实际可见性。后台下载不受影响，重回页面由原 180ms 刷新器读取最新任务状态。

## 有意保留的数据更新边界

进程历史、CPU 核心历史、网络抓包及 WMI/ETW/回调采集具有后台语义。部分监控页面的表模型本身承担有界事件保留，`flushPendingRows/flushPendingEvents` 同时负责队列消耗、丢弃计数和归档镜像，不能简单在开头加 `!isVisible()` 返回，否则会改变事件保留。该链已追踪并保留；本轮只删除纯样式的重复全页扫描，并修正不承担数据保存职责的下载表隐藏刷新。未宣称所有后台事件模型停止工作，也未测量实际性能收益。

原 Qt 系统选择器、原生插件、内存/HEX/反汇编编辑器内部与有持续采样职责的图表，均按其真实用途保留。可见业务文本没有新增；新增代码中的分组标题 `Object Type` 已是现有页面文本。
