# 子级 Tab 导航衔接

## 实际入口与布局归属

本轮修改共享导航，不重排业务页面。对照了内核对象命名空间、内核 I/O 管理两种父子导航，以及驱动对象信息的连体结果 Tab。

| 导航入口 | 页面类型 | 共享入口及处理 |
| --- | --- | --- |
| 内核 → 对象命名空间 → 总览/目录递归等 | 树清单、审计结果、字段详情 | StyleSquarePageTabsFrame → StyleChildPageTabs + StylePageTabsContentFrame |
| 内核 → 杂项 → 历史 NtQuery 等 | 查询与结果 | 相同子导航入口，业务参数/结果不改变 |
| 内核 → 内核审计与回调 → Inline Hook/IAT EAT 等 | 审计结果 | 相同子导航入口，保留惰性构造与首刷 |
| 内核 → 自身驱动子页 | 生命周期与状态诊断 | 相同子导航入口，保留依赖、状态和动作 |
| 内核 → I/O 管理 → SSDT/ShadowSSDT 等 | 现场清单、审计结果 | 相同子导航入口，保留查询和列配置 |
| 驱动 → 对象信息 → 详细结果页 | 公共摘要后的结果 Tab | StyleChildPageTabs + StyleJoinedResultTabs；保留连体结果造型及下方6px接缝 |

## 共享调整

- 普通父子导航使用同一固定内容层轨道，不再把子栏轨道降到页面深底。子导航使用自然宽度的圆角选中面和短强调标记，父栏保留贴内容的页签形状。
- 子栏选中、悬停和禁用前景分别校准真实底色；选中面与 QSS 的 1px/2px 内缩一致。仍沿用应用字体、现有图标、标题、索引和鼠标/键盘命中。
- 原 PageTabMotion 继续按实际 tabRect 和经过时间绘制。未新增计时器、控件覆盖层或业务页面动画；原父子方向切换和系统动画开关保留。
- 只在纯单子 Tab 或明确惰性壳转交导航时取消父级额外的6px接缝。工具行、splitter和并列内容仍终止转交；连体结果 Tab 继续使用自身规则。
- 子栏标签起点由8px改为共享6px，内容留白仍只有原框架一层负责。没有新描边、侧翼或外圆，也没有重排表格、splitter和详情。

## 核对与未验证边界

源码核对了上述六处真实入口及共享样式、动画、父子间隔、连体例外。未改动表格操作条、列组、规范字段源、复制/导出、排序/筛选和快照业务；这些业务行为没有在本轮运行验收。

按用户要求不运行自动 UI 测试、不创建伪窗口。编译单独报告；用户应重点查看对象命名空间与 I/O 管理的父子衔接、驱动对象的结果 Tab 是否仍连体，以及窄窗溢出箭头、连续切换、键盘焦点、深浅主题和缩放状态。

对象命名空间现有属性表与底部字段视图的同屏密度不属于本轮 Tab 改动，未把它或未登记的其它导航标记为已完成整页设计整改。共享修复的源码范围不等于全软件的实机视觉验收。
