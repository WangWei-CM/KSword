## 实体机 26H2 build 26300：Winbindex **无索引**

26H2 实体机的 R0 日志 (`.claude/memory/ksword-rxpf-mode1-realhardware-26h2-confirmed.md`) 对应 OS Build 26300.x，但 Winbindex 目前**没有收录任何** build 26300 的 ntoskrnl.exe（Flighting 期的 Insider 还没进 Winbindex 的发布追踪）。

现实选项：
1. **PDB ID 入口**：如果操作者从实体机导出了 ntoskrnl.exe 的 CodeView RSDS GUID+Age，可以直接用 NT Kernel Viewer 的 "PDB ID" tab 查询（Microsoft 公共符号服务器仍能按 GUID+Age 返 PDB，即使 Winbindex 没收录该 PE）。
2. **本地文件入口**：把实体机的 `C:\Windows\System32\ntoskrnl.exe` 走 NT Kernel Viewer 的 "本地文件" tab 让它本地解析。
3. 等 Winbindex 收录 26300 后重跑本流程。

无论哪种，**都不需要虚拟机**。

- **本文件追加 10 条新 UBR**（2113 / 2269 / 2336 / 2525 / 2605 / 2704 / 2804 / 2952 / 3086 / 3231）

格式与 kphdyn.xml 完全一致：`<data arch="amd64" version="10.0.28000.<UBR>" file="ntoskrnl.exe" hash="<sha256>" timestamp="<hex>" size="<hex>" added="2026-10-19T00:00:00Z">1</data>`。

每条的 `timestamp` 是 PE TimeDateStamp 字段原文；在当前 Windows 11 构建里 Microsoft 会用非墙钟的 repro-hash 值，这是预期的，公共符号服务器仍按这个 key 查 PE。

## 操作者下一步命令

### 1. 把 Winbindex 新发现的 build 28000 UBR 合进 corpus

`third_party/systeminformer_dyn/kphdyn.xml` 标注 `AUTOGENERATED, DO NOT MODIFY`，不要直接改它。两条路径任选：

**A. 临时合并一次性跑 generator**（推荐，不污染上游）

```powershell
$tmp = Join-Path $env:TEMP 'ksword-kphdyn-merged.xml'
# 把 extensions 的 <data> 行插到上游 </dyn> 之前
$upstream = Get-Content third_party/systeminformer_dyn/kphdyn.xml -Raw
$additions = (Get-Content tools/pdb_offset_generator/kphdyn-additions-ksword-20261019.xml -Raw) `
    -replace '(?s)^.*?<dyn>', '' -replace '</dyn>\s*$', ''
($upstream -replace '</dyn>\s*$', "$additions`r`n</dyn>`r`n") | Set-Content $tmp -Encoding UTF8

py -3.12 tools\pdb_offset_generator\ksword_pdb_profile_generator.py `
    --kphdyn $tmp `
    --version 10.0.28000 `
    --files ntoskrnl.exe `
    --corpus-root <private-corpus-root>
```

**B. 给 generator 加 `--kphdyn-extra` 支持**（长期方案，需要改一行工具代码）

修改 `ksword_pdb_profile_generator.py` 让 `iter_kphdyn_entries` 读两个文件。本次没动工具代码（避免越界）。

### 2. 跑完 generator 后发布到 pack v4

```powershell
py -3.12 tools\pdb_offset_generator\ksword_profile_release_sync.py `
    --source "<corpus-root>\profiles\ark_dyndata" `
    --release-root "Ksword5.1\x64\Release" `
    --pack-only --emit-pack --pack-version 4 `
    --pack-output "Ksword5.1\Ksword5.1\profiles\ark_dyndata_pack_v4.json" `

```
