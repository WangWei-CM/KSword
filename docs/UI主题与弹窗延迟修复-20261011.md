# 主题应用与弹窗首开延迟（2026-10-11）

用户报告应用主题和详情弹窗极慢，并补充 R0 提示框同样慢。本轮沿实际创建、Show、Palette/StyleChange 和主题应用调用链检查；依据源码确认重复工作，不将其换算成未经测量的耗时。按照用户要求，不运行自动测试、GUI 或伪窗口。

## 共享详情首开

- 原 `DetailWindowFramework` 首次 Show 固定收集三轮结构，每轮进入全部 `QStackedWidget` 子页。隐藏页即使不绘制字段，也会提前替换宿主、删除旧树、创建投影及登记主题。
- 现在收集只进入 Stack 当前页；第一次迁移 Tab/字段宿主导致结构改变时才重新收集。切页由原 Stack 的 `currentChanged` 在真实页身份确定后准备新页，保留原页对象、索引、Tab 文本和业务指针。
- 隐藏窗口或未选中页只保存结构 dirty，重新 Show/切页处理最新结构。专业 `keep_layout` 子树仍不进入通用迁移。
- `StructuredFieldView` 在已登记详情中且没有专业保留祖先时，隐藏旧树只保存最新规范文档和查询，不重建模型、测量列或安排布局。`document`、纯文本、复制全部/导出与通知代次继续来自即时更新的同一文档。专业工作台仍保持同步 `tree()` 行为。
- Qt 6.9.3 的 Stack 先 Show 新页、随后发 currentChanged；因此已登记详情中的旧树 Show 回填合并到可取消的队列，先让同步共享投影消费文档，避免刚重建树又删掉。没有被投影的视图仍回填最新文档。[Qt 对应版本源码](https://raw.githubusercontent.com/qt/qtbase/v6.9.3/src/widgets/kernel/qstackedlayout.cpp)
- 字段投影取消每个名称/值标签的独立主题 QSS。一个投影只维护一个精确拥有的主题块，字段属性决定正常、成功和错误色；真实语义变化才更新该项匹配。卡片、文本对比度及额外业务规则保留。

## R0 提示与共享消息框

- `MainWindow::handleR0DriverUnavailable` 原先在 UI 线程调用 `OpenSCManager/OpenService/QueryServiceStatusEx`，查完后才设置提示合并守卫。现在只读服务查询交线程池，先合并预检期间的失败通知，再把结果回投 UI 决定是否显示同一个提示；不预先启动或加载驱动。
- 状态未知时保持原先不弹框的行为。当前窗口身份、提示授权、实际显示状态、不再提醒配置以及服务启停状态须在回投时核验；不能把析构生命周期令牌误当成退出阶段或服务操作代次。
- 接受启停时递增操作代次，预检入口、工作线程、UI 回投和提示返回均核验门闩/代次；退出确认通过后撤销提示资格和通知生命周期。托盘隐藏保留合法提示行为，过期 SCM 结果不会覆盖较新的启停结果。交互预检以线程池优先级 1 排队，不能抢占已执行任务。
- R0 提示是 `QMessageBox`，明确不进入详情卡片框架。其共享主题原先每次读取 EXE 路径并查询 Shell 图标，改为优先复用现成窗口/应用图标，再从已映射模块资源取一次缓存。
- 消息框按钮仅在主次角色实际改变时补 polish，已有图标不反复重载；真实字体、正文、说明、详情、可用宽度、按钮几何或新宽度约束仍会重算窗口大小。重复 StyleChange 不再重算同一份布局。
- SCM 调用自身耗时与驱动实际启停时间仍由系统决定。后台化移除的是 UI 线程阻塞，不代表已经实测证明任意 R0 提示都能即时出现。

## 预加载边界

采用纯颜色配方缓存和当前页面按需准备。主题缓存可以跨窗口复用；业务 QWidget 不在后台线程构造，也不预创建全部详情实例。业务构造可能启动异步枚举、采样或驱动查询，提前创建会增加后台工作和内存，不能作为解决重复主题工作的手段。

原 SVG 着色已有分片与主题代次，背景图模糊已有源图/半径缓存，未再增加重复预热任务。存量未明确绑定的业务 QSS 仍需旧色映射保证主题正确，未直接删除该兼容链。

## 同批按钮补漏

用户随后指出进程列表设置的“关闭”和窗口属性控件检查的三个动作仍缺实底，要求全部改完再统一编译。

- 进程设置的底栏已调用 `StyleSecondaryFooter`，但该组件只绘分隔线；其父窗口/底栏的中性 QSS 又阻断共享按钮发现。现在 SecondaryPageLayout 记录精确拥有的中性样式块，FlatButtonTheme 只从颜色所有权判断中排除该块，额外业务颜色规则仍保留。
- 所有明确登记二级底栏的普通动作补 Neutral/Solid 及共享高度；继承 Auto 的按钮保留原语义 tone 并使用 Solid，已明确声明 Danger/Accent/Flat 或专用状态绑定的按钮不被降级。只检查该底栏布局，不进行全应用扫描。
- 控件检查拾取、暂停/继续、刷新改为现有 SVG 资源、共享实底和尺寸，原按钮身份及信号继续复用，悬停说明和状态图标保持实际含义。该页在窗口详情中复用同一创建工厂，不逐窗口复制实现。
