# 系统区域 UI 逐页源码复查（2026-10-11）

本清单覆盖 KernelDock、DriverDock、HardwareDock、HvmDock 的实际页面入口，以及 `UI/Hvm*` 的工具窗口、向导和动态页面工厂。依据实际 `addTab`、Stack 工厂、惰性初始化、窗口创建调用与局部样式所有权判断；未运行 GUI、自动测试、伪窗口或构建。文中的“已接入”是源码接入状态，不是视觉或性能实机验收。

路径约定：以下 `K/`、`D/`、`H/`、`U/` 分别表示 `Ksword5.1/Ksword5.1/KernelDock/`、`DriverDock/`、`HardwareDock/`、`UI/`。HvmDock 路径单独标出。相同工厂的实例仍逐一列出，设备数、驱动数或规则数不固定的集合在动态工厂表完整登记。

## 最终样式链与检查边界

- **主框架 F**：`StylePageTabsContentFrame` → `PageControlStyle` → 主页面表面/角片。pane 留白为 6，内层半径 8，外层半径 14；只归一化实际页根，卡片内部布局保留。纯嵌套 Tab 由最内层计一次留白；单子项惰性壳必须明确 `ksword_page_frame_host`。
- **控件 C**：普通按钮由共享按钮主题决定底面和状态，显式工具使用 Solid；`NormalizeToolbarRow/Control` 管高度，普通间距 8，列组走 `InstallSegmentedButtons`。独立输入使用 `StyleStandaloneInput`，搜索使用 `StyleSearchField`，组合框使用 `StylePrimaryCombo`。已被更近局部 QSS 覆盖时，不以“曾调用 helper”认定覆盖完成。
- **参数 P**：`ParameterWorkspace` 和 `StyleParameterSection` 管参数/结果分栏、窄窗折行及唯一滚动区。只读位图、HEX、代码编辑器自己的横向滚动和内部尺寸不是重复外壳。
- **详情 D**：普通 QDialog 由 `GlobalDialogTheme` 安装共享详情结构；显式 `InstallDetailWindowFramework/ConfigureDetailDialogRoot` 使用同一控制器。`StyleSecondaryWindow` 拥有工具窗颜色，保留其业务表单/固定操作区；StructuredFieldView 使用规范文档与共享投影。
- **采集 S**：明确区分采集和 UI 提交。硬件历史、磁盘 ETW、HVM 事件环、回调询问和用户开启的观测不因隐藏停止；已有隐藏投影/提交合并继续保留。没有新增持续动画定时器。
