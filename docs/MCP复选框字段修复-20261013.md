# MCP 复选框字段修复

## 复现与根因

- 使用真实主程序及仓库当前 stdio sidecar，GUI PID29220。默认自动R0/BGP安装关闭；选择“需要启用R0”提示中的“本次不再提醒”作为仅影响当前会话的复选框，不选择启用驱动按钮。
- `set_field(value=true, confirmed=true)`返回`unsupported_control`；同一对象`action(toggle)`可以改变checked，随后恢复原值。最小根因是字段适配仅有文本、数值、下拉和Tab，缺少可勾选按钮。
- 新增真实生产回归`tools/ksword_mcp/verify_live_checkbox.py`。修复前实际运行失败于unsupported_control，finally回读确认原值恢复。重复设置相同值的检查可抓到盲目toggle实现。

## 修正

- QAbstractButton中可勾选对象（QCheckBox、单选按钮、checkable按钮）公开布尔field_type、value和set_field能力。
- 只接收真实JSON布尔，同值不点击；变值使用原生click，保留clicked/toggled、互斥和业务槽。排队后再次检查是否可见、启用和可勾选；销毁和桥关闭通过QPointer保护。业务回滚返回value_rejected。
- 保留既有press/toggle。普通执行按钮不获得布尔字段权限，submit=true不适用于布尔字段；模型单元格勾选仍属于单独能力边界。
- 界面结构和主题不变，沿用原共享控件；未添加用户可见主程序字符串。未改动驱动或业务执行入口。
