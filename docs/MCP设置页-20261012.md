# MCP 设置页交付核对

| 导航入口 | 页面类型 | 共享布局入口 | 适用边界 |
| --- | --- | --- | --- |
| 顶部菜单 → 设置 → MCP | 设置和二级工具 | SecondaryPageLayout、SettingsPresentation、SettingsDock.Layout.h | 服务与客户端表单自适应双栏；参数独立滚动，沿用固定应用/取消 |
| MCP → 配置预览 / 操作日志 | 文本配置与日志输出 | SecondaryPageLayout、CodeEditorWidget | 共用输出 Tab；每份规范文档分别支持搜索、复制和导出，自身滚动 |
| MCP → 安装提示词 | Agent 安装引导文本 | SecondaryPageLayout、CodeEditorWidget | 可复制的编号短提示词，链接到完整安装指南；不在页面中执行安装 |

源码核对：

- 页根四边 6px，双栏使用共享间距，表单保持自然高度与统一标签对齐，窄窗按服务/客户端顺序纵排。表单/预览混合页新增共享 `CreateSecondaryFormScroll`，只观察已登记宿主并合并几何更新；未改变其它整页设置滚动区。
- 普通输入和选择由标准主题接入；启用使用 Accent，停止/浏览/复制使用 Neutral，真实 SVG、共享 32/18px 尺寸和提示。状态来自实际监听器，区分停止、运行和启动失败。
- 页签使用既有二级设置导航，预览不另套详情框架。未新增数据表、列组、快照或字段详情，表格操作条要求不适用。
- 本次启停与待保存自动启动偏好分开，保留应用/取消语义；自动启动默认关闭。启动失败保留原因并允许重试，停止释放管道与旧对象身份。
- JSON 与 TOML 使用当前进程 PID 和经过转义的路径，复制完整规范文档。复制动作的实现进行源码核对，自动验收不写用户剪贴板。
- 新增用户文本同步 zh-CN/en-US；新源码登记主工程与 filters。未改变命名管道的身份/权限校验。

操作日志增量交付：

- 入口为“设置 → MCP → 操作日志”；原配置预览与日志共用下方空间，上方服务状态/设置仍可见。只使用共享导航与只读编辑器，清空按钮沿用标准 SVG/尺寸/中性语义，空态提供独立提示。
- 主窗口是日志唯一源，最多保留1000条；设置窗口通过排队信号增量接收。重开设置和启停 MCP 保留记录，清空同步所有打开的日志视图；记录不自动落盘。
- 记录服务启停/失败、客户端系统 PID、请求白名单方法与 UUID、响应状态和机器错误、派发回执的 dispatching/dispatched/failed/cancelled/interrupted。成功轮询不重复记录，参数、读取结果及未验证身份原文不进入日志。
- 源码对照了现有只读文本/报告页与 `CodeEditorWidget` 的增量追加、容量裁剪和滚动保持实现；继续复用现有主题和保存语义，双语条目定点新增。
- 上文构建和 GUI 证据属于设置页初版，不能用于新增日志功能。日志增量按用户“改完直接提交，不需要测试”的要求，只做源码与差异核对，未编译、未运行语言包/主题门禁、未执行测试或 GUI 验收。
