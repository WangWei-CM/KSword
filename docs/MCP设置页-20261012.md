# MCP 设置页交付核对

| 导航入口 | 页面类型 | 共享布局入口 | 适用边界 |
| --- | --- | --- | --- |
| 顶部菜单 → 设置 → MCP | 设置和二级工具 | SecondaryPageLayout、SettingsPresentation、SettingsDock.Layout.h | 服务与客户端表单自适应双栏；参数独立滚动，沿用固定应用/取消 |

源码核对：

- 页根四边 6px，双栏使用共享间距，表单保持自然高度与统一标签对齐，窄窗按服务/客户端顺序纵排。表单/预览混合页新增共享 `CreateSecondaryFormScroll`，只观察已登记宿主并合并几何更新；未改变其它整页设置滚动区。
- 普通输入和选择由标准主题接入；启用使用 Accent，停止/浏览/复制使用 Neutral，真实 SVG、共享 32/18px 尺寸和提示。状态来自实际监听器，区分停止、运行和启动失败。
- 页签使用既有二级设置导航，预览不另套详情框架。未新增数据表、列组、快照或字段详情，表格操作条要求不适用。
- 本次启停与待保存自动启动偏好分开，保留应用/取消语义；自动启动默认关闭。启动失败保留原因并允许重试，停止释放管道与旧对象身份。
- JSON 与 TOML 使用当前进程 PID 和经过转义的路径，复制完整规范文档。复制动作的实现进行源码核对，自动验收不写用户剪贴板。
- 新增用户文本同步 zh-CN/en-US；新源码登记主工程与 filters。未改变命名管道的身份/权限校验。
