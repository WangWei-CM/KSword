# 默认标准主题与布局约束

主程序在首个业务窗口之前安装 `UI/StandardWidgetTheme`。普通Qt控件从创建起继承共享外观、度量和热主题绑定；页面只组合业务内容、声明动作语义并选择布局框架。

## 布局先于交付

根 `AGENTS.md` 是唯一设计规范。每页必须记录真实导航入口、对应页面类型和共享布局入口，至少符合一种布局规范。参数/执行使用ParameterWorkspace，列表/审计使用共享结果与详情容器，设置使用SecondaryPageLayout，对象详情使用统一详情框架，监控和专业工作台遵循其类型规则。混合页面按内容职责组合，不把小弹窗纵向堆叠无意义地铺满大窗口。

区内字段使用自然高度；参数独立滚动、执行动作固定，宽屏采用合理分栏或双列，窄屏切换布局。伸缩空间属于结果、图表、预览和正文。新增规范不能当作旧页已经视觉验收。

## 默认组件

- 布局默认边距6px、间距8px；普通独立单行控件至少28px，随字体自然增长。显式固定/紧凑尺寸、组合控件内部与表格单元格编辑器保留。
- 普通按钮、独立输入、数值框和下拉框自动绑定共享主题；具体主动作/风险色由页面声明。Combo的内容最小高度补偿上下padding，Popup项尺寸保持原有配方。
- 参数正文中的普通QGroupBox自动成为标题＋细分隔线；独立分组为无描边圆角卡片，标题放在内部。MainWindow与文件详情不再用旧图例式规则覆盖共享结构。
- 普通QSlider使用6px轨道、18px圆把手；QProgressBar保留原业务对象，绘制细轨道与独立数值，静态/隐藏进度停止动画，忙进度遵守系统动画选项。
- 普通Tab默认接共享样式和动画；已有父子/结果/专业导航的显式角色优先，保持原对象、索引和输入语义。
- 已有绑定和真正业务局部QSS继续拥有自身语义；新普通页面不得靠复制局部QSS逃避标准主题。专业保护只用于专业子树，不属于普通页面的布局豁免。

## 透明背景

透明模式保留窗口/页面背景策略，数据区域使用轻透衬底，输入、菜单和弹窗保留可读底色。表格默认文字同时按黑白背景端点校准，风险刷子、热度刷子和语法色保持数据语义；不通过所有QWidget铺实底遮住窗口透明效果。

## 真实检查入口

主程序“杂项 → 主题检查”使用ParameterWorkspace，直接创建普通按钮、输入、数值、Combo、GroupBox、Slider、ProgressBar、Tab和表格，不逐控件写皮肤。动态新增输入验证显示后的生命周期接入；普通多行文本仅用于控件皮肤样本，不承担业务日志/代码编辑器职责。

“重新检查”读取真实绑定与尺寸，仅作为诊断；“保存检查截图”抓取当前真实页面到临时目录，便于视觉核对。计数、源码审核和编译均不等于视觉合规，最终检查结果单独记录。
