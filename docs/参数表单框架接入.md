# 参数表单页框架

实现：`Ksword5.1/Ksword5.1/UI/ParameterWorkspace.h/.cpp`。
已逐页接入 26 个参数操作页，另有 5 处专业页面只统一明确的参数区，见文末清单。

## 布局与接入

`ParameterWorkspace(page, parameterWidth)` 建立参数栏和结果栏。参数正文独立滚动，参数栏底部的执行动作固定；宽度不足 860 个 Qt 逻辑像素时改为上下排列。分隔条可拖动，普通窗口缩放不重置用户的分栏比例。

参数与结果面板均使用 16px 等边内边距；正文至少 10pt（原像素字号至少 14px），保留字体家族与更大的用户字号。参数区在当前可用宽度内排版，长下拉选项不撑宽控件，长复选框/单选框按实际宽度换行，保留原对象、文字、可访问名称和业务信号。普通表单仅将 `DontWrapRows` 升级为 `WrapLongRows`，不会覆盖调用方的 `WrapAllRows`。

参数密集、日志较少的页面可明确调用 `workspace->useWideParameterLayout(60)`，宽屏初始分栏按参数 60%/结果 40% 分配；两个方向分别保存用户拖动比例。`ArrangeParameterColumns(layout, primary, secondary, minimumColumnWidth)` 将页面选择的分区排成两列，列宽不足时按原阅读顺序回到单列。请求构造、创建进程、BCD、渲染基准及系统变速、虚拟定位已逐页选择使用；常用参数默认展开，任意命令和低频结构继续按具体页面折叠。

```cpp
auto* workspace = new ks::ui::ParameterWorkspace(page, 480);
pageLayout->addWidget(workspace);

// 分组内容和业务信号仍由页面创建，不通过扫描猜测参数用途。
auto* section = new QGroupBox(sectionTitle, page);
auto* form = new QFormLayout(section);
form->addRow(fieldLabel, existingInput);
ks::ui::StyleParameterSection(section);
workspace->parameters()->addWidget(section);

// 低频参数可用 FoldParameterSection 包装普通、非 checkable 分组。
workspace->parameters()->addWidget(ks::ui::FoldParameterSection(advancedGroup));
workspace->actions()->addWidget(executeButton);
workspace->actions()->addWidget(resetButton);
workspace->actions()->addStretch();
workspace->results()->addWidget(resultWidget, 1);
workspace->finish();
```

- `parameters()`、`results()`、`actions()` 返回框架拥有的布局；调用方不要删除这些布局或把同一个布局同时挂到两个父容器。
- `finish()` 在页面控件添加完毕后调用，给参数区中的独立单行输入、数值框和下拉框补齐底色与统一行高，并规范动作栏间距。后续动态加入的参数区可单独调用 `StyleParameterFields(container)`。
- `StyleParameterSection(group)` 使用标题、分隔线和组间留白；其属性只作用于显式登记的分组，不改变其他页面的组框。
- 参数与结果面板、单行输入和编辑区均以底色区分，不描外轮廓。仅保留分区及固定操作区的淡分隔线；焦点通过填充变化提示。折叠标题使用小号低对比空心折角，保留按钮的键盘、提示和勾选语义。
- 可编辑多行字段使用输入底色；只读日志与结果面板同底，并同步项目编辑器 palette，避免出现黑色行号条或突兀的当前行。参数分组按自然高度排列，不把剩余高度摊到字段行距中。
- `FoldParameterSection(group, expanded)` 改为折叠标题与内容体。标题取传入时的分组标题；不要用于承载启用开关的 checkable QGroupBox。折叠只控制可见性，不改子控件值、启用状态或业务连接。
- 结果区可放表格、项目编辑器或页面自己的结果 Tab；框架不自动加快照、对比、复制、导出按钮。

## 逐页重排原则

不要把原来横跨整屏的四列、六列表格布局直接挪进窄参数栏。标签和值保持接近，复杂地址/路径可独占一行，相关开关跟随所属字段，低频参数折叠或放入明确命名的子页。禁止折叠必要的执行确认项。

优先保留已有业务控件对象以及验证器、信号连接、权限确认和默认值。表格编辑器、数值框/下拉框内部的 QLineEdit 不单独铺第二层底色。多行输入与日志继续使用项目的 CodeTextEdit / CodeEditorWidget。

框架不会自动发现或改造其他大页。布局由各页明确接入；禁止以关闭水平滚动条代替重排过宽的字段行。编译成功不等同于逐页 GUI 验收。

## 保留专业主体的参数区适配

- DDMA：保留通道表、专业内存编辑器及同址复核，只拆分拥挤的地址/长度/动作行并统一参数区。
- 桌面绘制：结果显示在桌面，保留单列表单，不制造空白结果栏。
- DSE 状态页：没有待填写参数，保留状态/定位/操作结构，仅统一分区样式。
- 创建桌面弹窗：保留已有两列参数/摘要和固定确认区，基础字段纵排，统一三组参数样式。
- Scanner 安全字节编辑：两个字段纵排、参数独立滚动、应用固定，保留备份和风险确认。

防火墙规则/事件、ARP/DNS/路由、服务、启动项、句柄、权限/会话表格，欢迎与性能仪表盘，以及注册表、hosts、磁盘/十六进制/文件系统取证等专业工作区保留原布局。HVM 保留生命周期步骤与独立证据 Tab，避免破坏操作次序。

## 普通状态页与专业工作区翻新

保留专业结构仍需更新视觉呈现。`StyleWorkspacePage(page, margin)` 只设置页面阅读字号下限、等边留白和画布；`StylePrimaryContentPanel(panel, false)` 为明确面板提供无描边实底，在主工作区与独立窗口均可使用。`StyleWorkspaceTextViews(container)` 同步项目文本编辑器的底色与真实 palette；不扫描或修改业务数据。
