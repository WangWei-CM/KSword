# 工具区与结果 Tab 连体布局

## 适用结构

公共操作或状态组件位于结果 Tab 上方时，整组采用连续工具底色：顶部保留外圆角，工具区下沿与 Tab 之间零间隔；Tab 的 pane 不再另加6px内边距，普通结果页壳也不重复内缩。表格外边界因此与整条 Tab 栏等宽。

共享入口为 `StyleJoinedResultTabs(tabs, header)`。调用页负责明确的局部分组，避免清掉无关分区或页脚的间距。页签选择、滑动动画、原 splitter 和业务对象保持原行为。外框凹角继续只属于真正的方角工作区。

普通 QWidget 页壳可归零外围布局；专业编辑器、池分析、参数卡片等自身布局保留。部分专业 QWidget 没有 Q_OBJECT，不能依靠 Qt 元对象把它误判成普通页壳。

## 逐页接入

共24个业务文件、25个源码接入点；窗口内层工厂与HAL/WDF组件会在多个实际页面复用。

| 模块 | 接入位置 |
| --- | --- |
| 进程 | Cross-View 查询工具行与结果Tab；保留原详情分割器 |
| 网络 | 网络审计状态头、防火墙状态头 |
| 监控 | WinAPI 过滤条与事件/覆盖结果 |
| 注册表 | 搜索选项与现有树/结果分割区；结果Tab与右侧表格等宽 |
| 插件 | 宿主管理的扫描摘要、输出与诊断Tab |
| 驱动 | DriverObject 查询、结构摘要与证据结果 |
| 内核 | 回调遍历、回调规则、IOCTL、HAL/WDF、SLAT/IOMMU |
| 内存 | 进程选择工具头、内存消费者、Hyper-V、PFN归因、系统内存审计 |
| HVM | 生命周期摘要与控制/证据页签 |
| 扫描/转储 | 来源、状态与结果分类 |
| 杂项 | 应用控制、右键菜单整理 |
| 窗口 | 顶部状态工具头及GUI/Session、Hotkey/Hook、Clipboard/Message-Only、GPU/Display/Watchdog四组结果标题 |
| Other | 窗口枚举工具头与窗口/桌面结果；底部状态栏间隔保留 |

有查询头和专业摘要/图表的页面使用普通页头壳容纳它们，专业控件保留自己的主题绑定。全根布局只有工具头和Tab时使用零spacing；存在页脚或其他分区时只对相邻组件建立局部零spacing分组。

## 保留的结构

- 内核分类/IPC、权限账户、WFP/NDIS等直接父子导航保留现有层级。
- 文件、权限、句柄、硬件主导航及启动项West侧栏继续使用分类布局。
- 属性/详情弹窗、外部原生插件窗口保持独立框架。
- 磁盘HEX编辑器、原始内存和其它专业编辑器不与下方高级页签强行拼接。
- 回调独立日志Tab没有共同的上方查询头，不强行连接相邻规则内容。
- 未再进入的旧网络连接管理构造路径不作无用途改动。
