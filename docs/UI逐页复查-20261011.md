# UI 逐页复查与补漏（2026-10-11）

本轮从 `MainWindow.cpp::initializeDockManager` 的 17 个主导航入口和 3 个辅助 Dock 展开，沿实际 `addTab/insertTab`、惰性构建、详情窗口创建与动态结果工厂追踪。不是对控件名的批量替换，也不是仅检查父页面是否调用过样式 helper。复查基线为 `ab9df9bf`。

按用户要求，不启动自动测试、GUI 或伪窗口。下表与链接清单记录**源码接入与修复**；运行效果和性能改善由用户使用原主程序实测。动态设备、原生插件和数据生成页的实例数不固定，清单登记完整创建工厂及其生成集合，不虚报运行过的页面数量。

## 保留范围与验收

独立底板、普通输入/动作和页面框架采用共享规范；连体分段、专业 HEX/反汇编/图表内部、系统选择器与外部原生插件保留实际控件语义。各例外在三个逐页清单中附原因，不能仅用“专业页面”跳过普通外围输入和动作。

监控的部分事件模型同时承担有界事件保留、丢弃计数和归档镜像，不在隐藏时提前中止 flush。详情首开、任意字体/主题下的真实滚动、DWM 裁剪和响应速度仍需原主程序实测。正常 Release 编译结果以本轮最终构建输出为准，不把源码覆盖清单等同于逐页视觉验收。
