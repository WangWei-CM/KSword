# 工具、权限、窗口、注册表、服务及设置逐页复查（2026-10-11）

本表从导航注册、页面构造、惰性工厂及动态结果工厂展开。路径相对 `Ksword5.1/Ksword5.1/`。状态“保留”表示已检查所列构造与最终样式路径，没有在本轮改动该页；不是 GUI 验收结论。未运行程序、自动测试、离屏或伪窗口。本文件不记录编译结果。

## 检查口径与本轮修复

- **框架**：`StylePageTabsContentFrame` 管理主页面外围 6px 留白与 14px 外角；已有内容 8px 圆角保留。纯嵌套导航不重复累加。惰性代理必须有 `ksword_page_frame_host`，否则只清理壳而未清理真实页外围。
- **控件**：搜索、独立输入、数值与下拉通过页面明确调用的共享 API 维护；不能只调用 `NormalizeToolbarRow` 就认定颜色也被接管。
- **最终所有权**：检查 `changeEvent`、`applyThemeStyle`、列组切换与右键自定义路径是否重新写旧 QSS。原 QSS 是构造残留还是仍生效分别处理。
- **布局**：参数区唯一外滚动、执行区固定；专业编辑器自己的文档滚动不作为重复壳删除。并列独立数据表保留各自滚动。
- **业务状态**：保留真实禁用、风险提示、危险动作确认、模型项语义色、原列组和快照工作流。通用表格栏的重复宿主由共享层处理，本轮不复制一套页面策略。

本轮定点修复：

1. 权限工作台七个惰性页明确标记代理，避免真实页默认边距与外框重复。
2. 权限快照 PID 数值输入补共享输入绑定。
3. 声音来源、剪贴板保护、注册表优化、窗口审计的列组状态/换肤路径移除分段安装后的旧按钮 QSS；只更新共享选择状态。窗口详情查询动作在换肤后也恢复共享按钮几何。
4. 扫描器与转储分析的动态宽表工厂接入共享 A/B/C 分段，覆盖生成结果全集；右键自定义仍清空预设选择。转储从零列加载真实列后重放当前预设的逻辑保持。
5. 扫描器文件目标输入补独立底面绑定。
6. 注册表值编辑器的名称、类型、十六/十进制数值及字节长度字段补独立输入/下拉主题；保留专业字节编辑器和控制台数据色块。
